║           CIVIC RESOLVE — HOW TO RUN (CMD GUIDE)            ║
╚══════════════════════════════════════════════════════════════╝

REQUIREMENT — Install these first (one time only):
  • Python 3.10+  → https://python.org/downloads
  • Node.js 18+   → https://nodejs.org

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 1 — Extract the ZIP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Right-click civic-resolve-final.zip → Extract All
Choose a location e.g. C:\Users\ELCOT\civic-resolve\

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 2 — START BACKEND (CMD Window 1)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Open Command Prompt (search "cmd" in Windows)

cd C:\Users\ELCOT\civic-resolve\civicbridge_work\civic-resolve-v2\backend
pip install -r requirements.txt
python app.py

✅ You should see:
   🚀 Civic Resolve Backend starting on http://localhost:5000

KEEP THIS WINDOW OPEN.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 3 — START FRONTEND (CMD Window 2)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Open a NEW Command Prompt window

cd C:\Users\ELCOT\civic-resolve\civicbridge_work\civic-resolve-v2\frontend
npm install
npm start

✅ Browser opens automatically at http://localhost:3000

COMMON ERRORS & FIXES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
"Failed to fetch"
  → Backend CMD window was closed. Reopen and run python app.py

"npm is not recognized"
  → Install Node.js from nodejs.org, restart CMD

"pip is not recognized"
  → Install Python from python.org, restart CMD

Port 5000 already in use:
  netstat -ano | findstr :5000
  taskkill /PID <number> /F
  then run python app.py again

Dashboard shows blank:
  → Sign out, register a new account
